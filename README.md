# Murkwire

Static Astro landing page for the Murkwire concept and its interactive demo.

![Murkwire homepage showing the headline and interactive code demo](docs/homepage.png)

## Run locally

Use Node.js 22.23.4 or later on a supported even-numbered release line.

```sh
npm ci
npm run dev
```

Run `npm run build` to generate the static site in `dist/` and `npm run preview` to preview that build.
